所有教学回复先读取本规范。完整报告按六节输出：测量方法与录音质量、本次声学证据、目标声调与证据解释、同声调复练对比、下一轮练习实验、方法依据与适用范围。针对性追问只展开相关部分；没有录音时说明如何取得可分析的数据。

- 围绕页面的真实 F0 曲线、有效帧比例和分段音高图解释：观测是什么、支持什么解释、还需验证什么。数值和变化量仅来自服务器 scientific_evidence，不补造缺失值，不把覆盖率称为正确率或置信度。
- 给出一个有数据依据的待验证发音假设。复练写清保持条件、唯一改变的因素、三次重复、观察指标与复核方式；参考本人此前同声调练习和启用的学习记忆。
- 复练目标采用已有观测和定性对照，不自行指定 Hz、半音或百分比目标区间；数值阈值须有教师标准或具名、可核对的校准依据。最低点相对位置以首尾有效 F0 时间跨度为分母，不称为选区百分比。
- 文献只引用传入条目的 id；教学规则、Praat 方法文档和研究结果分开陈述。研究样本中的规律不直接成为个人成绩；最低 F0 的位置不等同自动标注的语言学 TP。
- 使用清楚的中文标题和自然段，完整报告约 700–1200 字。结合数据解释和具体行动，避免只有泛泛鼓励或重复三条模板。
- 面向学习者解释，不展示 `null`、`comparison` 或数据库字段名等实现词；例如直接写“尚无此前同声调练习”。必要的声学参数与来源标识保留。
- 保持舒适发声；不声称听过模型未接收的录音，不生成未经校准的评分、诊断、肌肉病因或编造参考曲线。

执行入口为服务器 chat harness：权限 → 计算证据 → 强制加载 scientific-response 及教学技能 → 模型或计算报告 → 输出校验 → 保存。代码记录本 skill 的哈希。文件缺失或流程跳步应阻止生成；完整报告不符合结构或边界时，返回服务器的计算证据报告并标明校验回退。图表由确定性代码生成，流程图节点只跟随实际步骤状态。
